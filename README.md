# My Full Stack Web Development Journey

Hey! I'm diving into the **Full Stack Web Development** course from the University of Helsinki—a totally free, comprehensive program that teaches modern JavaScript, React, Node.js, and more. Here’s my roadmap and how I’m tackling it.

---

## 🎯 What I’m Learning
This course is all about **hands-on, project-based learning**. I’m building:
- **Single-page applications** with React
- **Backend services** using Node.js (both RESTful and GraphQL APIs)
- Real-world skills like TypeScript, React Native, CI/CD, Docker, and database integration

---

## 📚 Course Structure
The course is broken into **14 parts**, each taking roughly **15–20 hours** of focused work. I’m moving at my own pace, but the structure encourages mastery—I won’t move on until I’ve really grasped the current section.

### My Learning Flow:
1. **Read the material** for one part (it’s designed to be consumed in order)
2. **Code along** with the examples, making small tweaks to really understand
3. **Complete exercises**—some build into larger projects across multiple parts
4. **Check my work** against the provided GitHub repos
5. **Only move forward** once I feel confident with the concepts

---

## 🧠 Prerequisites I Met Before Starting
- ✅ **Solid programming foundation** (I’m comfortable in at least one language)
- ✅ **Basic web & database knowledge**
- ✅ **Familiarity with Git**
- ✅ **A problem-solving mindset** (this course encourages independent learning)

I didn’t need prior JavaScript or React experience—the course starts from the basics.

---

## 🏆 What I’m Earning
- **A free certificate** upon completion
- **Free ECTS credits** from the University of Helsinki
- **A portfolio of real projects** I built step-by-step

---

## 📈 My Progress Approach
- **Parts 1–4:** I’m doing all non-asterisk exercises to build a strong foundation. Asterisk exercises are extra credit, but skipping them won’t block my progress.
- **Parts 5–13:** Every exercise matters equally.
- I’m using the **submission system** to track my exercise times and compare my pace with others.

---

## 🗺️ Why I’m Taking This Course
I wanted a structured, university-level curriculum that’s hands-on, free, and respected in the industry. This course is known for its practical approach—I’m not just reading tutorials, I’m building real applications from the ground up.
